## Состав решения (`NotesApp.sln`)

### 1. `NotesApp_v1` — Базовая версия (`v1.0`)
- Простой интерфейс для создания, редактирования, сохранения и удаления заметок;
- Локальное хранение в базе данных SQLite (`notes_v1.db`);
- Автоматическое сохранение текстовых копий в папку `Заметки\<Заголовок>.txt`;
- Кнопки **«Открыть заметку»** (открывает `.txt` в Блокноте) и **«Папка»** (открывает каталог `Заметки`).

### 2. `NotesApp_v2` — Многофункциональная версия «Заметки Pro» (`v2.0`)
- Оптимизированная БД SQLite (`notes_v2.db`: `PRAGMA journal_mode = WAL`, `synchronous = NORMAL`, `foreign_keys = ON`, `cache_size = 10000`, B-Tree индексы);
- Категории, приоритеты (`Обычный`, `Средний`, `Высокий`), теги, закрепление заметок вверху списка;
- Встроенные чек-листы задач (`[ ]` / `[x]`), быстрая вставка даты/времени и готовые шаблоны («План на день», «Список дел», «Конспект»);
- Режим защиты **«Только чтение»**, **Архив** и локальные **Напоминания**;
- Мгновенный поиск в реальном времени (`Ctrl+F`) и фильтрация по категории, приоритету и архиву;
- Переключение между светлой и темной темой оформления;
- Автоматическое сохранение в `Заметки\<Заголовок>.txt`, открытие в Блокноте и резервное копирование всей базы в JSON (**«Бэкап JSON»**).
