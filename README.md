## Состав решения (`NotesApp.sln`)

### 1. Версия 1.0 — Базовая (`NotesApp_v1`)
Лёгкая и простая версия приложения заметок:
- Хранение заметок в локальной базе данных SQLite (`notes_v1.db`);
- Автоматическое сохранение каждой заметки в отдельный файл `Заметки\<Название>.txt` в папке программы;
- Создание, редактирование, удаление заметок (синхронизировано с файлами в папке `Заметки`);
- Кнопки **«Сохранить»**, **«Открыть заметку»** (открывает `.txt` файл в Блокноте) и **«Папка»**.

### 2. Версия 2.0 — Многофункциональная (`NotesApp_v2`)
Расширенная версия с улучшенным интерфейсом и оптимизированной БД SQLite (WAL, внешние ключи, B-Tree индексы):
- **Категории, теги и приоритеты** (с возможностью добавления новых категорий);
- **Закрепление заметок (`★`)** и режим защиты **«Только чтение» (`🔒`)**;
- **Живой поиск** (с поддержкой кириллицы без учёта регистра) и фильтры по категории, приоритету и архиву;
- **Архив** (мягкое удаление с возможностью восстановления);
- **Панель инструментов:** чек-листы задач (`[ ]` / `[x]`), быстрая вставка даты и времени, шаблоны (*План на день*, *Список дел*, *Конспект*), копирование и дублирование заметок;
- **Напоминания** по дате и времени с фоновым таймером уведомлений;
- **Резервное копирование** всех заметок в `.json`, сохранение заметок в `.txt` в папку `Заметки`;
- **Светлая и тёмная темы оформления**.

## Запуск
Откройте файл `NotesApp.sln` в **Visual Studio 2022** и выберите нужный проект (`NotesApp_v1` или `NotesApp_v2`) как запускаемый, либо выполните из консоли:
```bash
dotnet build NotesApp.sln
```
